# 工单查询功能 PRD

## 一、需求概述

### 1.1 功能定位

为管理员提供工单查询功能，支持多条件组合查询、分页浏览和详情查看，便于日常工单管理和监控。

### 1.2 使用角色

| 角色 | 权限说明 |
|------|----------|
| 管理员 | 可查询所有工单，支持详情弹窗 |

### 1.3 使用频率

低频（偶尔查看），查询结果需要清晰展示。

---

## 二、功能需求

### 2.1 查询条件

| 条件 | 类型 | 说明 |
|------|------|------|
| 工单编号 | 精确/批量 | 支持单个或多个编号批量查询，用逗号分隔 |
| 创建人 | 模糊匹配 | 前缀匹配，如输入 "张" 匹配 "张三丰"、"张无忌" |
| 创建时间 | 范围查询 | 默认近7天，支持自定义起止日期 |

### 2.2 分页展示

| 配置项 | 值 |
|--------|-----|
| 每页条数 | 20条 |
| 页码跳转 | 支持 |
| 默认排序 | 创建时间倒序 |

### 2.3 返回字段

| 字段名 | 说明 | 脱敏 |
|--------|------|------|
| 工单编号 | 工单唯一标识 | 否 |
| 标题 | 工单标题 | 否 |
| 状态 | 工单状态 | 否 |
| 创建人 | 工单创建人 | **是** |
| 创建时间 | 工单创建时间 | 否 |
| 更新时间 | 最后更新时间 | 否 |

### 2.4 详情弹窗

支持点击工单查看详情弹窗，展示工单完整信息。

## 四、数据脱敏规则

### 4.1 脱敏字段

| 字段 | 原始值 | 脱敏后 |
|------|--------|--------|
| 创建人 | 张三丰 | 张*丰 |
| 创建人 | 李明 | 李* |

### 4.2 脱敏算法

单字符姓名：保留首字，替换尾字为 `*`
多字符姓名：保留首字和尾字，中间替换为 `*`

## 五、验收标准

| 编号 | 标准描述 | 测试要点 |
|------|----------|----------|
| AC1 | 支持按工单编号精确查询 | 输入编号 W001，返回对应工单 |
| AC2 | 支持多个编号批量查询 | 输入 "W001,W002,W003"，返回3条工单 |
| AC3 | 支持创建人前缀模糊查询 | 输入 "张"，返回所有张姓创建人的工单 |
| AC4 | 支持创建时间范围查询 | 选择日期范围，返回范围内的工单 |
| AC5 | 默认显示近7天工单 | 未选择时间时，自动显示7天内工单 |
| AC6 | 分页展示每页20条 | 结果超过20条时分页显示 |
| AC7 | 支持页码跳转 | 点击页码可跳转至指定页 |
| AC8 | 默认按创建时间倒序 | 最新创建的工单显示在前面 |
| AC9 | 创建人字段脱敏 | 张三丰 显示为 张*丰 |
| AC10 | 支持详情弹窗 | 点击工单可查看完整信息 |
