# 产品需求文档（PRD）

## 目录结构

```
prd/
├── <模块名>/
│   └── <YYYYMMDD>_<功能名>_v<版本号>.md
└── README.md
```

## 文档命名规则

| 组成部分 | 格式 | 说明 |
|----------|------|------|
| `<模块名>` | 小写字母+下划线 | 如 `user`, `order`, `workflow` |
| `<YYYYMMDD>` | 年月日 | 创建日期 |
| `<功能名>` | 小写字母+下划线 | 如 `login`, `query_order` |
| `<版本号>` | v1, v2... | 迭代版本 |

## 文档模板

```markdown
# [功能名称]

## 一、需求背景

## 二、功能概述

## 三、核心流程

## 四、页面设计

## 五、数据字段

## 六、业务规则

## 七、边界条件

## 八、验收标准

## 九、相关文档
```
