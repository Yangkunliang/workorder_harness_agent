# 技术设计文档

## 目录结构

```
tech/
├── <模块分类>/
│   └── <YYYYMMDD>_<模块名>_v<版本号>.md
└── README.md
```

## 文档命名规则

| 组成部分 | 格式 | 说明 |
|----------|------|------|
| `<模块分类>` | 小写字母+下划线 | 如 `user`, `order`, `workflow` |
| `<YYYYMMDD>` | 年月日 | 创建日期 |
| `<模块名>` | 小写字母+下划线 | 如 `user_service`, `order_api` |
| `<版本号>` | v1, v2... | 迭代版本 |

## 文档模板

